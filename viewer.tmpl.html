Claude Protein Design Prompt Analysis

This is a dissection of the protein binder design campaign prompts Anthropic released as Anthropic/claude-protein-binder-design: a prompt for a single protein target, and a multi-target version.

To help navigate and interpret the prompts, the viewer shows the prompt text on the left, a per-block annotation on the right, and a quick navigation overview between them. The prompt text is the unmodified source. The annotations are this project's own reading of it.

The 50 clauses that are mechanically enforced are additionally re-coded as Python, which you can read side by side with the prose using the As Python button. That code is a reconstruction for reading, not the campaign's implementation.

The Flow tab, shown first, is a diagram of the overall orchestration: which agents, state stores and external surfaces exist, and which prompt rules give each one authority over the others. Click a node to list its rules, each tied to the prompt block it quotes.
